# NSL-3130AA-Windows-Binary
NSL-3130AA-Windows-Binary + OpenCV

- Windows용으로 컴파일된 바이너리 입니다. (This is a binary compiled for Windows.)
- 일부 weights, pb, caffemodel, dll 등의 사이즈 문제로 압축하여 배포합니다. (Due to size issues, some weights, PB, CaffeModel, and DLL files are compressed for distribution.)
- 압축을 풀고 dll 파일의 위치로 NSL-3130AA.exe 파일을 복사하십시오. (Extract the compressed files and copy the NSL-3130AA.exe file to the location of the DLL files.)  
- NSL-3130AA.exe를 실행 하십시오. (Run NSL-3130AA.exe.)

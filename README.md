# NSL-3130AA-Windows-Binary
NSL-3130AA-Windows-Binary + OpenCV

- Windows용으로 컴파일된 바이너리 입니다.
- This is a binary compiled for Windows.
  
- 일부 weights, pb, caffemodel, dll 등의 사이즈 문제로 압축하여 배포합니다.
- Some weights, pb, caffemodel, dll, etc. are compressed and distributed due to size issues.
  
- 압축을 풀고 dll 파일의 위치로 NSL-3130AA.exe 파일을 복사하십시오.
- Unzip and copy the NSL-3130AA.exe file to the location of the dll file.
  
- NSL-3130AA.exe를 실행 하십시오.
- Run NSL-3130AA.exe.
